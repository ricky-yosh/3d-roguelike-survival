# 3d-roguelike-survival

> A fast-paced **3D horde survival roguelike** built in **Godot**, focused on procedural generation, modular abilities, and performance-optimized large-scale combat.
> Designed as a **polished portfolio project** that highlights clean architecture, scalable gameplay systems, and real optimization techniques.

---

## 🎮 Game Goals

Step into a procedurally generated arena.
Face overwhelming enemy hordes.
Grow stronger every wave.
See how long you can survive.

This project aims to capture the **satisfying chaos of horde-slayer games** while showcasing the **engineering behind scalable, replayable gameplay**.

---

## 🛣️ Development Roadmap

### Phase 1 — Vertical Slice

* [ ] Player movement and core combat
* [ ] Single enemy with chase + attack AI
* [ ] One **seeded procedural arena**
* [ ] Wave → points → upgrade → next wave loop
* [ ] Basic HUD (HP, points, wave)
* [ ] Death screen and restart

---

### Phase 2 — Abilities & Upgrades

* [ ] Data-driven **ability framework**
* [ ] 3–4 unique abilities (dash, nova, turret, etc.)
* [ ] Upgrade selection UI between waves
* [ ] Stat modifiers (damage, cooldown, AoE, projectiles)
* [ ] Initial balance pass

---

### Phase 3 — Enemies & Wave Director

* [ ] Two new enemy archetypes (ranged, brute)
* [ ] Difficulty scaling via **spawn budgeting**
* [ ] Navigation polish and hit feedback
* [ ] Death VFX and combat readability improvements

---

### Phase 4 — Meta Progression & Persistence

* [ ] Save/load system
* [ ] Between-run meta currency
* [ ] Unlockable upgrades or abilities
* [ ] Run summary with **seed + statistics**

---

### Phase 5 — Performance & Optimization

* [ ] Object pooling (enemies, projectiles, VFX)
* [ ] Reduced-frequency AI updates for distant enemies
* [ ] Enemy caps with stat-based scaling
* [ ] Profiling + written optimization notes
* [ ] Stable framerate during heavy combat

---

### Phase 6 — Polish & Presentation

* [ ] Juice: camera shake, hit flashes, particles, sound
* [ ] Controller support & accessibility options
* [ ] Clean menus and visual cohesion
* [ ] Gameplay GIFs / trailer footage
* [ ] Playable **web or downloadable demo**
* [ ] Final technical documentation
